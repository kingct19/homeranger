# Home Ranger Services — website asset package

Start by opening `asset-preview.html` in your browser. This is an asset gallery, not a finished website.

## Included
- `logos/`: primary and reversed logos in SVG + PNG, and a simplified SVG favicon.
- `mascot/`: transparent HVAC technician hero illustration.
- `icons/`: 12 original, matching SVG interface/service icons plus an SVG sprite.
- `styles/`: CSS brand variables and reusable component styles; JSON design tokens.
- `patterns/`: subtle roofline repeat for section backgrounds.
- `docs/`: brand guide, developer handoff, asset provenance, and generation prompts.
- `references/`: the three original supplied brand boards, unchanged.

Copy `logos`, `mascot`, `icons`, and `patterns` into your website's public asset folder. Import `styles/brand.css` into your project. Read `docs/BUILD-PROMPT.md` before handing the package to Cursor or another developer.

The HVAC board is the authority for colors and messaging. It differs from the general services board. This package uses Home Ranger Services, not UncleBreeze.

The mascot is a raster recreation derived from the supplied concept art. The primary and reversed logos are outlined vector adaptations, not original designer masters. The favicon is a simplified vector adaptation. The icon set is new vector artwork coordinated with the board. Font files are not included.
